title: Gold Recovery Process Optimization
description: |
  Developed a machine learning pipeline to predict gold recovery across multiple purification stages in an industrial metallurgical process.

  Implemented data validation (MAE ≈ 0 for formula verification), feature alignment to prevent data leakage, time-series split (80/20), forward-fill imputation, and outlier filtering based on concentration thresholds.

  Optimized a Random Forest Regressor using cross-validation and a custom weighted sMAPE metric.

  Results: Final weighted sMAPE < 10%

  This project demonstrates applied machine learning for nonlinear industrial process modeling and operational performance optimization.
